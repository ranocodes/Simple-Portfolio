# Simple Portfolio

A personal portfolio website built with HTML and CSS. Designed to showcase personal information, skills, projects, and contact details through a simple web interface.

## Development

1. Clone the repository:

   ```bash
   git clone https://github.com/ranocodes/Simple-Portfolio.git
   cd Simple-Portfolio
   ```

2. Open `index.html` in your browser to view the website.

### Notes

- `index.html` contains the website structure and content.
- `style.css` handles the styling and layout.
- Image assets are stored in the project root.
- The website is deployed on [Vercel](https://portfolio-tau-eight-ff83nxsmc9.vercel.app/).
